健身打卡 桌面应用
==================

功能：健身周计划打卡 + 身体数据记录与图表 + 训练计划查看，数据保存在本地。

启动（开发）：
  npm start

打包安装包：
  npm run dist
  产物位于 dist/ 目录：
    - dist/健身打卡 Setup 1.0.0.exe  —— NSIS 安装包（可双击安装）
    - dist/win-unpacked/健身打卡.exe —— 免安装绿色版（直接运行）

注意：桌面版与浏览器版使用同一份 localStorage 数据（各存各的），
如需把网页版数据带到桌面版，请在网页版「数据」页导出记录，再到桌面版导入。
